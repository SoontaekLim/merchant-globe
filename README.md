# Merchant Globe

Merchant Globe는 실제 세계의 도시와 지리를 기반으로 하는 무역·경제 시뮬레이션 게임입니다. 현실 경제를 그대로 복제하기보다 게임성을 위해 재해석한 시장에서 작은 개인 상인부터 글로벌 무역회사까지 성장하는 것을 목표로 합니다.

## 현재 단계

현재는 **1차 MVP 단계**입니다. 가장 먼저 검증할 가설은 다음과 같습니다.

> 도시별 가격 차이와 시장 변동만으로 무역이 재미있는가?

현재 실행 가능한 프로토타입은 `prototype/web-v0`에 있습니다.

## 핵심 루프

**정보 확인 → 상품 선택 → 매입 → 이동 → 시장 변화 → 판매 → 이익 → 성장**

## 저장소 구조

```text
merchant-globe/
├── README.md
└── prototype/
    └── web-v0/      # 현재 실행 가능한 MVP 프로토타입
```

본 개발이 시작되면 필요에 따라 `apps/`, `packages/`, `server/`를 추가합니다. 프로토타입 코드를 제품 코드로 억지로 승격시키지 않고, 검증된 경제 규칙과 테스트만 본 구현으로 옮기는 것을 원칙으로 합니다.

## MVP 원칙

- 무역의 재미를 먼저 검증한다.
- 항상 같은 상품/항로가 정답이 되지 않게 한다.
- 경제는 완전 랜덤이 아니라 학습 가능한 특성을 가진다.
- 정보 자체를 성장 요소로 취급한다.
- 이동에는 시간과 비용이 존재한다.
- 반복 작업보다 판단의 순간을 만든다.
- GPS, 실제 지도, PvP, 길드, 전투, 여행 인증 등은 핵심 경제 검증 이후로 미룬다.

## 현재 프로토타입

버전: **0.2**

주요 구현:

- 5개 도시 / 12개 상품
- 도시별 재고 및 수요
- 재고·수요 기반 동적 가격
- 거래량에 따른 시장 충격과 매수/매도 스프레드
- 매입/판매, 평균 매입가, 보유 손익
- 화물 적재량
- 도시 이동 시간 및 운송비
- 시장 이벤트
- 시간 경과에 따른 재고/수요 회복
- 기본 업그레이드
- 30일 플레이
- 경제 엔진 자동 테스트

실행 방법과 상세 내용은 [`prototype/web-v0/README.md`](prototype/web-v0/README.md)를 참고하세요.
