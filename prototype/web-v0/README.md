# Merchant Globe MVP 0.2

실제 세계 도시를 배경으로 한 무역 경제 시뮬레이션의 초기 실행 버전입니다.

## 현재 구현된 기능

- 도시 5개: 서울, 부산, 후쿠오카, 오사카, 상하이
- 상품 12개
- 도시별 상품 가격 특성
- 도시별 상품 재고 및 수요
- 재고·수요에 따른 동적 가격 변화
- 플레이어 매입 시 현지 재고 감소 및 가격 상승 압력
- 플레이어 판매 시 현지 재고 증가 및 가격 하락 압력
- 거래 수량에 따른 평균 체결가(시장 충격)와 매수/매도 스프레드
- 같은 도시에서 자가 펌핑 후 즉시 되파는 차익거래 방지
- 시장 재고를 초과하는 매입 제한
- 시간이 지나면 재고와 수요가 평시 수준을 향해 회복
- 수요 급증 / 공급 증가 시장 이벤트
- 매입 / 판매 / 평균 매입가 / 보유 손익
- 화물 적재량
- 도시 이동 시간 및 운송비
- 화물칸 확장 업그레이드
- 30일 플레이 및 결과 통계
- 개발 서버 상태 확인 API

## 가격 구조

현재 가격은 크게 네 요소로 결정됩니다.

```text
도시 장기 가격 특성
× 기본 시세 변동
× 재고 압력
× 수요 압력
```

재고가 평소보다 적으면 가격이 오르고, 재고가 많으면 가격이 내려갑니다.
수요가 평소보다 높으면 가격이 오르고, 낮으면 가격이 내려갑니다.

시장 이벤트는 가격을 직접 배율로 조정하지 않고 재고 또는 수요를 변화시키는 방식으로 동작합니다.

## 실행

Python 3만 있으면 별도 패키지 설치 없이 실행됩니다.

```bash
cd merchant-globe-mvp
python3 server.py
```

브라우저:

```text
http://127.0.0.1:8000
```

서버 확인:

```text
http://127.0.0.1:8000/api/health
```

## 테스트

Node.js가 설치되어 있다면:

```bash
npm test
```

의존성 설치는 필요하지 않습니다.
