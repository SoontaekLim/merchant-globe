# Merchant Globe MVP 0.3

실제 세계 도시를 배경으로 한 무역 경제 시뮬레이션의 초기 실행 버전입니다. 0.3의 핵심은 **시장 정보 자체를 성장 자원으로 만드는 것**입니다.

## 현재 구현된 기능

- 도시 5개: 서울, 부산, 후쿠오카, 오사카, 상하이
- 상품 12개
- 도시별 상품 재고 및 수요
- 재고·수요 기반 동적 가격
- 거래량에 따른 시장 충격과 매수/매도 스프레드
- 시장 재고를 초과하는 매입 제한
- 시간 경과에 따른 재고·수요 회복
- 수요 급증 / 공급 증가 시장 이벤트
- 평균 매입가, 보유 손익, 화물 적재량
- 도시 이동 시간 및 운송비
- 화물칸 확장
- 30일 플레이 및 결과 통계
- 시장 정보망 및 오래된 정보(stale intel)
- 시장 사건의 정보 정확도 제한
- 경제 엔진 자동 테스트

## 0.3 시장 정보 시스템

현재 머무는 도시는 12개 상품의 가격·재고·수요를 실시간으로 확인할 수 있습니다.

다른 도시는 기본적으로 정보를 볼 수 없습니다. 직접 방문하면 그 시점의 전체 시장 정보가 기록되며, 시간이 지나면 해당 정보는 오래된 정보가 됩니다.

정보망을 성장시키면 원격 도시 보고서를 자동으로 받습니다.

| 단계 | 이름 | 원격 자동 정보 | 갱신 주기 | 다음 단계 비용 |
|---|---|---:|---:|---:|
| Lv.0 | 현지 장부 | 없음 | - | 6,000 |
| Lv.1 | 지역 정보망 | 도시별 핵심 상품 3개 | 3일 | 14,000 |
| Lv.2 | 광역 정보망 | 도시별 핵심 상품 6개 | 2일 | 28,000 |
| Lv.3 | 글로벌 정보망 | 전체 12개 | 1일 | 최고 단계 |

정보망이 낮을수록 다른 도시의 시장 사건도 정확한 영향과 종료 시점을 알기 어렵습니다.

이 시스템의 목적은 플레이어에게 다음 판단을 만드는 것입니다.

> “이 시세는 2일 전 정보인데, 지금 출발해도 아직 기회가 남아 있을까?”

## 가격 구조

```text
도시 장기 가격 특성
× 기본 시세 변동
× 재고 압력
× 수요 압력
```

시장 이벤트는 가격을 직접 변경하기보다 재고 또는 수요를 변화시킵니다.

## 실행

저장소 루트에서:

```bash
cd prototype/web-v0
python3 server.py
```

브라우저:

```text
http://127.0.0.1:8000
```

## 테스트

```bash
cd prototype/web-v0
npm test
```

별도 npm 의존성 설치는 필요하지 않습니다.
